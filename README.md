# Neovim Configuration

Минимальная модульная конфигурация Neovim со светлой темой.

## Структура

```
.
├── init.lua                 # Главный файл конфигурации
└── lua/
    ├── core/
    │   ├── options.lua      # Базовые настройки vim
    │   ├── clipboard.lua    # Буфер обмена (OSC 52)
    │   └── keymaps.lua      # Горячие клавиши
    └── plugins/
        ├── init.lua         # Менеджер плагинов (lazy.nvim)
        ├── theme.lua        # Тема Rose Pine
        ├── neo-tree.lua     # Файловый менеджер
        ├── bufferline.lua   # Вкладки буферов
        ├── cmp.lua          # Автодополнение
        ├── which-key.lua    # Подсказки горячих клавиш
        ├── toggleterm.lua   # Терминал + lazygit
        ├── sops.lua         # Шифрование файлов (SOPS)
        └── treesitter.lua   # Парсинг и контекст
```

## Плагины

- **lazy.nvim** - менеджер плагинов
- **rose-pine** - цветовая схема (светлая тема Dawn)
- **neo-tree** - файловый менеджер
- **bufferline** - вкладки открытых буферов
- **nvim-cmp** - автодополнение (пути, буфер, командная строка)
- **which-key** - подсказки для горячих клавиш
- **toggleterm** - терминал внутри nvim + lazygit
- **nvim-sops** - шифрование/расшифровка файлов через SOPS/age
- **nvim-treesitter** - парсинг синтаксиса
- **nvim-treesitter-context** - отображение родительского контекста в YAML и других файлах

## Горячие клавиши

Leader клавиша: `Space`

### Файловый менеджер
- `Space + e` - открыть/закрыть Neo-tree

### Буферы
- `Tab` - следующий буфер
- `Shift + Tab` - предыдущий буфер
- `Space + x` - закрыть текущий буфер
- `Space + X` - закрыть все буферы кроме текущего

### Git
- `Space + g + r` - git restore текущего файла
- `Space + g + G` - открыть lazygit

### SOPS
- `Space + e + f` - зашифровать файл
- `Space + d + f` - расшифровать файл

### Редактирование
- `<` / `>` в visual mode - сдвиг отступа с сохранением выделения

### Буфер обмена
- `y` - копировать в системный буфер (через OSC 52)
- `p` - вставить из системного буфера

## Установка

1. Скопируйте конфигурацию в `~/.config/nvim/`
2. Запустите `nvim`
3. Плагины установятся автоматически при первом запуске

## Особенности

- Буфер обмена настроен на OSC 52 — позволяет копировать текст с удалённых серверов по SSH напрямую в буфер обмена хостовой машины. Работает также внутри tmux
- Относительная нумерация строк
- Табы конвертируются в 4 пробела
- Автоматическая подсветка текущей строки
- Без swap файлов
