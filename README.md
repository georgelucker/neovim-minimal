# Neovim Configuration

Минимальная модульная конфигурация Neovim со светлой темой.

## Структура

```
.
├── init.lua                 # Главный файл конфигурации
└── lua/
    ├── core/
    │   ├── options.lua     # Базовые настройки vim
    │   ├── clipboard.lua   # Буфер обмена (OSC 52)
    │   └── keymaps.lua     # Горячие клавиши
    └── plugins/
        ├── init.lua        # Менеджер плагинов (lazy.nvim)
        ├── theme.lua       # Тема Rose Pine
        └── neo-tree.lua    # Файловый менеджер
```

## Плагины

- **lazy.nvim** - менеджер плагинов
- **rose-pine** - цветовая схема (светлая тема Dawn)
- **neo-tree** - файловый менеджер

## Горячие клавиши

Leader клавиша: `Space`

### Файловый менеджер
- `Space + e` - открыть/закрыть Neo-tree

### Буфер обмена
- `y` - копировать в системный буфер (через OSC 52)
- `p` - вставить из системного буфера

## Установка

1. Скопируйте конфигурацию в `~/.config/nvim/`
2. Запустите `nvim`
3. Плагины установятся автоматически при первом запуске

## Особенности

- Буфер обмена настроен на OSC 52 (работает через SSH/tmux)
- Относительная нумерация строк
- Табы конвертируются в 4 пробела
- Автоматическая подсветка текущей строки
- Без swap файлов
